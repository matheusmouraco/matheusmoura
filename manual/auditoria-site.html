O prompt · cole no ChatGPT ou Claude
Prompt de auditoria 
Analise todo este site e faça uma auditoria completa de responsividade, performance e SEO técnico. Depois aplique as correções.

Site: [COLE A URL DO SEU SITE AQUI]

RESPONSIVIDADE (mobile e tablet):
1. Verifique todos os breakpoints. Garanta que o layout funciona em 360px, 390px, 768px, 1024px e 1440px.
2. Corrija qualquer overflow horizontal (scroll lateral indesejado).
3. Garanta que imagens usam max-width: 100% e height: auto.
4. Botões e links com área de toque mínima de 44x44px.
5. Fontes legíveis no mobile (mínimo 16px no body, sem zoom forçado).
6. Menu hambúrguer funcional.
7. Verifique a meta viewport no head.
8. Tabelas e grids devem empilhar ou ter scroll próprio no mobile.

PERFORMANCE / CORE WEB VITALS:
1. Otimize o LCP: imagem principal com fetchpriority="high" e preload das fontes críticas.
2. Converta imagens para WebP/AVIF com srcset e lazy loading (exceto a imagem do hero).
3. Elimine CLS: defina width e height em todas as imagens.
4. Inline o CSS crítico e adie o CSS/JS não crítico.
5. Remova bibliotecas e scripts não utilizados.

SEO TÉCNICO:
1. Title e meta description únicos em cada página (title até 60 caracteres, description até 155).
2. Hierarquia correta de headings (um único H1 por página).
3. Alt text descritivo em todas as imagens.
4. Schema markup (JSON-LD) adequado ao tipo de negócio.
5. Open Graph e Twitter Cards configurados.
6. Canonical tags, sitemap.xml e robots.txt.
7. URLs amigáveis e links internos com anchor text descritivo.

Antes de alterar qualquer coisa, me mostre um relatório do que encontrou, organizado por prioridade (crítico, importante, melhoria). Depois que eu aprovar, aplique as correções uma seção por vez.

Como usar em 3 passos

  • Copie o prompt no botão acima e cole no ChatGPT ou no Claude.
  • Troque o [COLE A URL] pelo endereço do seu site e envie.
  • Leia o relatório. Você vai ver, por prioridade, o que está afastando cliente do seu site.
